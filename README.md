# 2ChO Skills

2ChO 团队的 Codex 技能。

| 技能 | 用途 |
| --- | --- |
| [2cho-exam-layout](skills/2cho-exam-layout/SKILL.md) | 按 2ChO 定稿版式排版和核对化学试卷、评分细则、答题卡及计分 TSV。 |

## 下载与安装

有仓库读取权限的团队成员可在 GitHub 仓库首页打开 **Code → Download ZIP**。解压后，将 `skills/2cho-exam-layout/` 整个目录放到 Codex 的个人技能目录，默认是 `~/.codex/skills/`。技能说明、参考文档、底图和配置都在该目录内。已有同名技能时请先保留自己的修改。

也可以在 Codex 中运行 `$skill-installer`，并提供这个目录链接：

```text
https://github.com/2ChOTeam/2ChO-Skills/tree/main/skills/2cho-exam-layout
```

安装后重启 Codex。发起任务时可用 `$2cho-exam-layout`，并附上需要排版的原稿。
